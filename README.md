# Vetstol - Ветеринарне обладнання

Веб-сайт компанії Vetstol, що спеціалізується на постачанні ветеринарного обладнання для різних галузей ветеринарії.

## 🌐 Live Demo

Переглянути сайт: [https://slavaleschenko.github.io/Vetstol/](https://slavaleschenko.github.io/Vetstol/)

## ✨ Особливості

- 📱 Адаптивний дизайн для всіх пристроїв
- 🎯 Зручна навігація по категоріях обладнання
- 📞 Форма зв'язку з клієнтами
- 🎨 Сучасний та професійний дизайн

## 🛠️ Технології

- HTML5
- CSS3
- JavaScript (ES6+)
- Адаптивна верстка

## 📁 Структура проекту

```
├── index.html              # Головна сторінка
├── pages/
│   └── categoryDetails.html # Сторінка деталей категорії
├── styles/css/             # CSS стилі
├── js/                     # JavaScript файли
├── assets/                 # Зображення та іконки
└── README.md              # Документація
```

## 🚀 Розгортання

Проект автоматично розгортається через GitHub Pages при кожному push до гілки `main`.

## 📧 Контакти

Для питань та пропозицій звертайтесь через форму на сайті.
